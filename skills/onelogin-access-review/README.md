# OneLogin連携アプリのアクセス権監査

OneLoginユーザーに割り当てられたアプリへのアクセス権を確認し、見直しが必要な候補と判断根拠を整理するスキルです。

## できること

| 調査方法 | 用途 |
|---|---|
| 全体棚卸し | 部署・職種別のアプリ保有率とログイン状況から候補を一次抽出し、詳細調査の対象を選ぶ |
| 指定ユーザーの詳細監査 | 現在のアプリ割り当てを、ユーザー状態・割り当て経路・同属性ユーザー・利用履歴から評価する |

標準の全体棚卸しでは同属性ユーザーのアプリ保有率を比較し、Role/Eventsの全件収集は行いません。属性が一覧で取得できない場合は必要な範囲で個別APIから補完し、比較不能なら明示します。全体棚卸し後は、確認候補と理由を表示し、詳細に調査するユーザーの選択を求めます。**CSV出力やユーザーコメント記録の希望は、詳細監査の結果を提示した後に確認します。** ただし候補一覧のCSVを明示的に求められた場合は、一次抽出結果として出力できます。

アプリ・部署・上長による絞り込み、CSV出力、承認後のユーザーコメントへの記録にも対応します。全体棚卸しの流れは、ZIP展開後の `references/usage-guide.md` の「3. 全体棚卸しを利用する」を参照してください。

## 利用を始める

登録済みの「OneLogin連携アプリのアクセス権監査」を選び、チャットで依頼します。

> OneLoginのアクセスレビューを開始してください。テナントはexampleです。まずテナント全体を棚卸ししてください。

表示された接続先を確認・承認した後、案内に従ってClient ID・Client Secretを入力します。カスタムユーザーフィールドがある場合は、監査に使用しない項目を確認してから調査を開始します。特定ユーザーを調査する場合は、依頼に対象のID・メールアドレス・ユーザー名などを添えてください。

## ドキュメント

詳細は、ZIPを展開した `onelogin-access-review` フォルダ内の `references/usage-guide.md` を参照してください。事前準備、監査の開始、全体棚卸し、詳細監査の結果の見方、CSV出力、コメント記録、保存ファイルの削除を説明しています。

## 利用前に確認すること

- 本SkillはOneLoginに登録された連携アプリへの**割り当て状況**を確認します。OneLogin管理画面そのものへのアクセス権や、連携先アプリ内部の細かな操作権限は監査対象ではありません。
- OneLogin API Credentialsの取得権限が必要です。**情報収集はRead All、ユーザーコメントへの記録はManage usersまたはManage All**を想定しています。コメント記録以外に割り当て・Role・Group・ユーザー状態を変更する機能はありません。
- 標準のチャット実行方式では、Client ID・Client Secretを今回のチャットに入力します。**入力内容は会話履歴に残ります。** 顧客情報や認証情報をAIサービスへ送信してよいか、利用する組織の規程と契約を確認してください。許可されない場合はチャットに認証情報を入力しないでください。
- **API認証情報をChatGPTのMemory・長期記憶・利用者プロファイルに保存／記憶させることは禁止しています。** ファイル、ログ、環境変数、監査成果物への永続化も禁止します。ただし、Skillの規定だけでは会話履歴やAIサービス側のデータ保持を停止できません。
- カスタムユーザーフィールドの値は、一覧を提示して利用者の除外希望を確認するまで監査に使用しません。機密情報を示す名称の項目は自動除外します。
- API取得結果にはユーザー情報や利用状況が含まれます。AIサービスへのアップロード、生成ファイルの保管、再利用、削除は組織の個人情報保護・機密情報管理規程に従ってください。認証情報の取り扱いは、ZIP展開後の `references/usage-guide.md` の「1. 利用前に準備するもの」、保存ファイルの削除は「7. 保存された監査ファイルを削除する」を参照してください。
- AIが示すのは人によるレビューのための候補と根拠です。権限不要の確定や権限削除は行いません。

## 配布・更新について

内部ID：`onelogin-access-review`。導入先に同じ内部IDのSkillがある場合は、上書きせず、既存環境の登録状態と保存データを確認してから更新してください。インストーラーは既存フォルダの上書きを拒否します。

外部配布・二次配布の可否、著作権表示、商標やロゴの利用、サポート窓口については**配布元の方針を確認**してください。本ZIPには利用許諾書や更新履歴を含めていません。

イベント種別一覧に掲載されていない履歴が見つかった場合、処理は継続しますが、結果の取得範囲は`partial`と表示します。未掲載のイベントを権限変更として自動的に解釈しません。
